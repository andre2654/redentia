# Imagens de /teses

Os `.png` desta pasta são as capas de tese servidas pelo backend como
`/teses/<slug>.png` (usadas no /mercado, /tese/[slug], busca etc).

A página /teses ("A grade", desde 02/11/2026) usa as mesmas capas nos cartões,
com um zoom ancorado à direita que deixa o selo "PESQUISA" desenhado na borda
esquerda da imagem fora do quadro (TesesGrade.vue, `tgr__capa-img`).
